Sports Learning Roadmap

按照你现在的水平，运动不只是“去运动”，而是每周有明确技能目标。

⛸ Figure Skating

当前：单足蛇形、后压步。

8周路线：单足蛇形稳定 → 后压步两侧 → 单脚内外刃 → 三转准备与基础 → 后滑单脚 → 一足旋转准备 → 基础步法连接。

暂时不急：不把跳跃作为这8周主目标。先把刃、单脚控制和转向打稳。

🏊 Swimming

当前：会蛙泳，正在学自由泳。

8周路线：身体位置 + 水下呼气 → 侧向换气 → 打腿/划臂 → 25m连续自由泳 → 50m自由泳 → 节奏与效率。

蛙泳作用：用作热身、恢复和耐力，不再作为主要技术目标。

🎾 Tennis

当前：正手、反手入门。

8周路线：固定动作框架 → 击球点 → 正反手交替 → 小碎步与回位 → 半场连续对拉 → 发球入门 → 简单回合。

当前优先：稳定性和击球点高于球速。

Weekly Load

固定：滑冰3次 + 游泳1次 + 网球1次。

周日：默认预留给徒步 / 户外，不再默认叠加游泳或第4次滑冰；晚上保留钢琴。

恢复规则：如果本周疲劳明显或没有徒步安排，周日直接作为恢复日；不需要补做运动。
