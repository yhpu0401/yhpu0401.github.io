你需要掌握的乐理

前8周先掌握 1–8 的基础，后面的内容随曲目逐渐加入。

1. 记谱与读谱

具体内容：五线谱、高音谱号、低音谱号、大谱表、中央C、加线、音名 C–B、landmark notes。

目标：看到常见音符后，逐渐不再一个格子一个格子数，而是直接对应琴键。

2. 节奏与拍号

具体内容：全音符、二分、四分、八分、十六分音符；休止符；附点；tie；2/4、3/4、4/4、6/8。

目标：即使弹错音，拍子也尽量不停。

3. 音程

具体内容：2度到8度；step / skip；旋律音程与和声音程；major / minor / perfect 的概念。

目标：开始按“方向 + 距离”读谱，而不是把每个音拆开翻译。

4. 音阶与调

具体内容：大调结构；自然、和声、旋律小调；scale degree；relative / parallel keys。

目标：理解调的结构，而不只是背按键。

5. 调号与五度圈

具体内容：升号和降号的顺序、常见调号、五度圈、相对大小调。

目标：看到调号能较快判断作品的基本调性。

6. 三和弦与转位

具体内容：大三和弦、小三和弦、减三和弦、增三和弦；原位、第一转位、第二转位。

目标：把三个音读成一个和弦整体。

7. 功能和声

具体内容：I、ii、iii、IV、V、vi、vii°；tonic / predominant / dominant；V7。

目标：能找出简单作品的 I–IV–V–I 等和声骨架。

8. 乐句与终止式

具体内容：phrase、authentic cadence、half cadence、plagal cadence、deceptive cadence。

目标：理解音乐中的“逗号”和“句号”。

9. 七和弦与声部进行

具体内容：diatonic seventh chords、转位、voice leading、non-chord tones。

10. 曲式

具体内容：binary、ternary、rondo、variation、sonata form。

11. 中高级和声

具体内容：modulation、secondary dominant、borrowed chords。

12. 复调与对位

具体内容：independent voices、imitation、counterpoint、fugue 基础。

目标：以后随 Bach Inventions、Sinfonias、WTC 系统提高。

长期传统古典路线

Technique
Hanon → Scales / Arpeggios / Chords → targeted advanced technique

Études
Czerny Op.599 → Op.849 → Op.299 → Op.740 → Chopin Études

Bach
Anna Magdalena → Little Preludes → Two-Part Inventions → Three-Part Sinfonias → French Suites → WTC

Classical
Clementi Sonatinas → Mozart Sonatas → Beethoven Sonatas

Romantic
Burgmüller Op.100 → Schumann → Chopin Preludes / Waltzes / Nocturnes → Études / Ballades / Scherzos → Liszt / Rachmaninoff

建议：读谱比当前演奏水平低很多的谱；技术练习以放松、均匀、固定指法为优先。
